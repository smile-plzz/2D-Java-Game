Under the hood

Every game here is a subclass of the same Game loop — a JavaScript port of a 2D game framework originally written in Java. Java no longer runs in browsers, so the framework's core (vector and rectangle math, input polling, easing equations) was ported to ES modules once, and each game is written against that same port.

Shared modules
ModuleUsed for
framework/game.js The update / draw game loop every game in the arcade runs on.
framework/vector2.js Positions, velocities and steering for every entity in every game.
framework/input.js Keyboard and mouse polling shared across all six games.
game/particles.js, game/audio.js The particle bursts and synthesised sound effects each game reuses.
